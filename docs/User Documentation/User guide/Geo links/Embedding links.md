# Embedding links

Embedded links are a highly useful tool for interface integration and web development. Geo-links offer the capability to generate and adjust iframe embeddable code that can be reused for the needs of creators and integrators.

To access the embed code, select a geo link and move to the right side bar menu. In the menu, look for the "<>" button and click on it:

The width and height of the iframe element can be adjusted directly in the "Embed link" window.
