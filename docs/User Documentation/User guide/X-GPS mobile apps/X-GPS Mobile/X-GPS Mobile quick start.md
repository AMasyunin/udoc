# X-GPS Mobile quick start

Follow these steps to learn how to work with X-GPS Mobile.

|                                                                                                                                                                                                  |                                                                                                    |
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
| Step 1. Download the app<ol start="1"><li><p>Open Google Play or App Store and enter X-GPS Mobile in the search field. </p></li><li><p>Select it and tap <strong>Install</strong>.</p></li></ol> | ![image-20250416-114036.png](..\..\..\attachments\8558fc16-7496-478a-8881-053b407a7724.png)  <br/> ||                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |                                                                                |

| Step 2. Log in<ol start="1"><li><p>Open the app.</p></li><li><p>Enter your username and password and tap <strong>Sign in</strong>. </p></li><li><p>If required, enter your server URL (by default, the Navixy server is used). Alternatively, use a QR code to bypass entering the URL and automatically configure your settings. </p></li></ol><br/>> [!IMPORTANT] If you forgot your password, tap the corresponding button and enter your email address. You will receive an email with a link to reset your password. <br/> | ![Login screen](..\..\..\attachments\e70cb32e-8c7e-4cd6-acc6-955daf6f8410.jpg) ||                                                                                                                                                                                                         |                                                                                     |
