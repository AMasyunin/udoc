# X-GPS Monitor first start

|                                                                                                                                                                                              |    |
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---|
| You can download the application for free from Google Play or App Store. <br/> Go to the store and type X-GPS in the search field. <br/> Select **X-GPS Monitor** and click "Install". <br/> |    |

### Log in

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |    |
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---|
| At the first launch, the application will offer you to scan a QR code, which can be found on the login page of the web interface. <br/> After scanning the QR code, enter your username and password and click the **"Log in"** button. <br/> If you forgot your password, click the corresponding button, enter your email address, and captcha. After that, you will receive an email with a link to reset your password. <br/> After successful login, you will see the map screen. <br/>  <br/> |    |

### Main tools

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |                                                                                           |
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------|
| The following items are available on the main screen: <br/><ol start="1"><li><p><strong>Sidebar.</strong> Pressing a button brings up a menu where you can access information about the user, balance, list of devices, and other controls.</p></li><li><p><strong>Show trackers.</strong> Click to select which trackers to display - all, one, or a group. You can also enable "Follow the object" and the map will automatically center on one device.</p></li><li><p><strong>Map type.</strong> Allows you to select from the list of available maps, and also enable the traffic display.</p></li><li><p><strong>Notifications List.</strong> Displays all unread notifications.</p></li><li><p><strong>Show location.</strong> Center the map at your current location.</p></li><li><p><strong>Scale.</strong> You can change the map scale with the "+" and "-" buttons.</p></li></ol>  <br/> | ![x-monitor-interface.png](..\..\..\attachments\d66d70e1-5636-4d4f-8076-9229fc657ca4.png) |
