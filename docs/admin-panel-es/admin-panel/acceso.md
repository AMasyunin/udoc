# Acceso

Navixy le permite crear múltiples cuentas para sus empleados para acceder al panel de administración. Hay dos roles de usuario disponibles:

1. **Rol de administrador:** Este rol tiene el nivel más alto de privilegios en el panel de administración. Los usuarios con el rol de administrador pueden acceder a todas las funciones y configuraciones de la plataforma, incluyendo la gestión de usuarios, facturación y gestión de dispositivos. Solo puede haber una cuenta (la cuenta principal) con este rol por cada instancia del panel de administración.
2. **Rol de empleado:** Este rol está diseñado para usuarios que requieren acceso limitado al panel de administración. Los usuarios con el [rol de empleado](#employee-role) pueden realizar solo tareas específicas y tienen acceso restringido a ciertas funciones y configuraciones.

Al crear instancias del panel de administración, es importante saber qué rol elegir según las responsabilidades y necesidades de acceso del usuario del panel de administración. Los roles de empleado deben asignarse a usuarios con responsabilidades o necesidades de acceso limitadas.

## Rol de empleado con derechos limitados

Puede crear cuentas de usuario adicionales que pueden acceder al panel de administración de Navixy con derechos limitados. Esto le permite delegar el uso del panel de administración a sus empleados con acceso restringido a información sensible y acciones críticas. Esta función puede ser útil para equipos con múltiples miembros, como representantes de ventas y especialistas de soporte técnico, que necesitan acceso a la plataforma sin otorgarles privilegios completos de administrador.

Las capacidades de este rol de usuario incluyen:

- Agregar nuevos usuarios
- Modificar datos de usuarios actuales
- Agregar nuevos rastreadores
- Clonar rastreadores actuales
- Cambiar el propietario de un rastreador
- Cambiar el plan de datos del rastreador
- Analizar datos entrantes con la consola aérea

Las cuentas de usuario de este tipo no pueden:

- Eliminar usuarios
- Eliminar rastreadores
- Agregar, cambiar o eliminar planes
- Cambiar la configuración de la plataforma

Para agregar una cuenta de empleado con derechos limitados a su Panel de Administración de Navixy, póngase en contacto con nuestro equipo de éxito del cliente.
