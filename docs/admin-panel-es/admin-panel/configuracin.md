# Configuración

El Panel de administración de Navixy le permite configurar su plataforma. Puede acceder al Panel de administración de cualquiera de estas formas:

- inicie sesión a través de su portal de cliente [https://portal.navixy.com](https://portal.navixy.com) (recomendado)
- inicie sesión directamente en [https://panel.navixy.com](https://panel.navixy.com)
