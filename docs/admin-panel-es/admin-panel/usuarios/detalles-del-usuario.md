# Detalles del usuario

Para ver los detalles de una cuenta de usuario seleccionada, simplemente haga clic en el nombre del usuario en la [Lista de usuarios](https://panel.navixy.com/#users).

Esto le llevará a una nueva página donde puede acceder a la siguiente información:

- Tipo de cuenta: corporativa o individual
- Información completa del usuario incluyendo nombre/título, detalles de contacto, saldo y sección de comentarios
- Rastreadores del usuario con información breve sobre cada activo
- Transacciones de facturación con tipos de transacción y descripciones detalladas

La barra de herramientas ubicada en el lado derecho de la pantalla con un menú contextual le permite actualizar el perfil del usuario, cambiar el saldo, restablecer la contraseña, iniciar sesión en la plataforma como el usuario y obtener una clave de sesión.
