## Features

The X-GPS Monitor mobile application provides a wide range of tools for working with the map, trackers, tasks, etc.

### Object list

Click the ![image-20250304-153340.png](../../User%20Documentation/User%20guide/X-GPS%20mobile%20apps/X-GPS%20Monitor/....../attachments/af5df82c-164c-4f54-80a9-55513aece351.png) icon in the upper left corner of the screen to display the side menu.\
The following items are available in the menu:

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |                                                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <ol start="1"><li><strong>User information and balance.</strong> Click on your username to get extended information on recent transactions.</li><li><strong>Devices list.</strong> All your trackers are displayed here. Using the buttons in the upper right corner, you can search for devices you need or filter the list by various parameters.</li><li><strong>Chat messages.</strong> Used for online chatting with employees using the X-GPS Tracker application.</li><li><strong>Tasks.</strong> You can view all active and completed tasks and reassign them.</li><li><strong>Add asset.</strong> Activate new GPS devices directly from the mobile application.</li><li><strong>Settings.</strong> Allows you to configure mobile notifications, sort the trackers list, and specify a different server address.</li><li><strong>Log out.</strong> Click to sign out. The next time you start the application, you will have to re-enter your username and password.</li></ol> | <p><img src="../../User%20Documentation/User%20guide/X-GPS%20mobile%20apps/X-GPS%20Monitor/....../attachments/3b6a3269-cfaa-4926-b65a-a767ff5172d8.png" alt="image-20250304-152237.png"><br></p> |

### Object view

If you click on the object in the list, the application will show you its location and display brief information—GPS signal level, current speed, and when the device last sent data. Also, additional buttons will appear at the top of the screen:

|                                                                                                                                                                                                                                                                                                                                                                                                               |                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <ol start="1"><li><strong>Object details.</strong> Detailed information about the GPS device and its settings.</li><li><strong>Events for the period.</strong> Show all events for a specific time interval.</li><li><strong>Tracks for the period.</strong> Show all trips for the selected time period.</li><li><strong>Unread notifications.</strong> Show all new events related to the device.</li></ol> | ![image-20250304-152338.png](../../User%20Documentation/User%20guide/X-GPS%20mobile%20apps/X-GPS%20Monitor/....../attachments/ce8681c5-318f-499b-86a0-d189c01c2e80.png) |

### Object status

By clicking on the ![image-20250304-153652.png](../../User%20Documentation/User%20guide/X-GPS%20mobile%20apps/X-GPS%20Monitor/....../attachments/8605027d-235c-4022-9531-8e095308ec0e.png) icon, you will get complete information about the current status of the device and its settings:

|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <ol start="1"><li>Tracker model, tariff, IMEI and current status.</li><li>GPS signal level, coordinates, speed, direction and address.</li><li>GSM signal level and carrier.</li><li>Information about the external power and the state of the built-in battery.</li><li>The status of all digital inputs.</li><li>Readings of all configured sensors.</li><li>Engine hours and odometer readings.</li><li>Outputs switching.</li><li>Access to tracking settings and others.</li></ol><p>And other information specific to certain tracker models.<br></p> | ![image-20250304-152800.png](../../User%20Documentation/User%20guide/X-GPS%20mobile%20apps/X-GPS%20Monitor/....../attachments/d888e46d-c161-4df7-a76d-ea7034775241.png) |
